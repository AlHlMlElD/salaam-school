# نظام إدارة مدرسة السلام

تطبيق إدارة مدرسي عربي باتجاه RTL. يشمل لوحات المدير والمدرس والطالب وولي الأمر، وإدارة الطلاب والفصول والمدرسين والمواد والحضور والدرجات والجداول والشهادات والمدفوعات والإشعارات والتقارير.

## التشغيل على Windows

1. ثبّت Node.js إذا لم يكن موجودًا على الجهاز.
2. افتح `start.bat` بنقرتين.
3. سيفتح التطبيق في المتصفح على `http://127.0.0.1:4173`.

أو افتح PowerShell داخل مجلد المشروع وشغّل:

```powershell
npm start
```

ثم افتح العنوان أعلاه يدويًا. لإيقاف السيرفر، أغلق نافذة الطرفية التي شغّلته.

## الحسابات التجريبية

يمكن الضغط على بطاقة الدور في شاشة الدخول، أو استخدام:

| الدور | البريد | كلمة المرور |
|---|---|---|
| المدير | `admin@salaam.edu` | `Admin@123` |
| المدرس | `teacher@salaam.edu` | `Teacher@123` |
| الطالب | `student@salaam.edu` | `Student@123` |
| ولي الأمر | `parent@salaam.edu` | `Parent@123` |

## البيانات والنسخ الاحتياطي

تُحفظ البيانات في IndexedDB داخل المتصفح وعلى الجهاز الذي شُغّل عليه التطبيق. من صفحة **الإعدادات** يمكن تصدير نسخة JSON أو استيراد نسخة سابقة، كما يمكن إعادة البيانات التجريبية.

هذه نسخة محلية للتجربة والتطوير: الحسابات والبيانات التجريبية ليست نظام مصادقة إنتاجيًا، ولا يوجد تزامن بين أجهزة متعددة. قاعدة المتصفح المحلية اختيرت بدل Realm Web لأن Realm Web يتصل بخدمة Atlas ولا يوفر قاعدة Realm محلية داخل صفحة المتصفح. لا تستخدم بيانات طلاب حقيقية أو حساسة قبل ربط التطبيق بخادم موثوق ومصادقة وقاعدة بيانات مناسبة.

المساعد الذكي يعمل محليًا على بيانات التطبيق. يمكن إعداد نقطة وسيطة لخدمة Claude من صفحة الإعدادات؛ لا تضع مفتاح API في المتصفح.

## التحقق

لتشغيل اختبارات الواجهة:

```powershell
npm test
```

الاختبارات تغطي الدخول حسب الدور، لوحات التحكم، إدارة الطلاب، الحضور، الدرجات، المدفوعات، الإشعارات، والانتقال على شاشة الهاتف.
